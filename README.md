**FinPulse** is a modern, high-performance personal expense tracking web application featuring a stunning **Dark Mode Glassmorphism UI**, monthly financial summary filtering, interactive Chart.js visual analytics, and robust LocalStorage data persistence.

---

## 🔥 Key Features

- 📊 **Dynamic Dashboard Cards**: Instant real-time calculation of **Total Balance**, **Total Income**, and **Total Expenses** with surplus/deficit trend indicators.
- 📅 **Monthly Summary Filter**: Dynamically filter all financial metrics, category doughnut breakdowns, and transaction history lists by specific month (`July 2026`, `June 2026`, etc.) or view `All Months`.
- 🎨 **Glassmorphism Dark Mode UI**: Translucent glass card containers with ambient glowing neon lighting (`backdrop-filter: blur(20px)`), smooth typography (*Plus Jakarta Sans*), and responsive layouts.
- 📈 **Visual Analytics**: Interactive Doughnut chart powered by Chart.js highlighting category expense breakdowns and top spending categories with percentages.
- ✍️ **Transaction Management**: Income/Expense toggle switches, category icons & badges (Food, Utilities, Salary, Entertainment, Shopping, Other), with date tracking.
- 🔍 **Real-Time Search & Category Filters**: Search by item title or amount, and filter by category or type instantly.
- 💾 **LocalStorage Data Guard**: Automatic state persistence with schema validation and exception guards.
- ✨ **Fluid CSS Animations & Custom Modal**: Keyframe entry (`@keyframes itemEnter`) and exit animations on list items, plus a custom Glassmorphism confirmation modal for resetting data.

## 🚀 Getting Started & Local Usage

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/nimesh-kavindya/FinPulse-Expense-Tracker.git
   cd FinPulse-Expense-Tracker
   ```

2. **Run Locally**:
   Open `index.html` directly in any standard web browser (Chrome, Edge, Firefox, Safari) or run a local static server:
   ```bash
   npx serve .
   ```

## 🛠️ Technology Stack

- **Frontend**: HTML5, Vanilla CSS3 (CSS Grid, Flexbox, Custom Variables, Keyframes)
- **Logic**: Vanilla JavaScript (ES6+ Modules, Array Methods, LocalStorage API)
- **Analytics Engine**: [Chart.js 4.4.0 CDN](https://www.chartjs.org/)
- **Icons & Typography**: [FontAwesome 6](https://fontawesome.com/) & [Google Fonts - Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans)
